# 香港粤语离线语音包

语言标识为 `yue`，声线为 `zh-HK-HiuGaaiNeural`，女声，语速 `-5%`。[Microsoft 语音支持表](https://learn.microsoft.com/azure/cognitive-services/speech-service/language-support?tabs=tts) 将该声线列为香港粤语。采用原有中文文稿的粤语朗读，字幕保持原文；并非粤语口语改写，也不新增语音识别。

## 使用

在控制台 `http://localhost:8765` 选择“粤语（香港）”，点击“试听粤语”确认浏览器声音可用，再勾选“启用离线语音”。先选语言再模拟游客到访，可用粤语迎宾。导览期间语言选择锁定；暂停会停止音频，继续讲解或重复会重新播放对应段落。浏览器禁用自动播放时，检查声音权限后重新勾选语音开关。

音频随 ROS 包安装在 `share/heritage_tour/voices/yue`，由本地 `/audio/yue/` 接口提供，不依赖系统安装香港语音。朗读只有在实际播放开始后才发送心跳；播放完成后才发送本段完成确认。旧段落的回调不会结束新讲解。播音中断时仍使用原来的安全暂停与字幕后备机制。异常告警可以在停车状态播出，播放结束不会解除故障。

`manifest.json` 记录每段文稿、时长与文件校验值。35 段导览音频覆盖当前界面使用的单人/三人欢迎、五区各三种讲解、10 条固定问答、常见异常和告别，另有 1 段试听。互动题目和答案解析仍保留原有屏幕交互。

## 重新生成

正常部署和播放不需要安装生成工具，也不访问外部语音服务。只有更新文稿、需要重新制作语音包时运行：

```bash
python -m pip install edge-tts==7.3.1 imageio-ffmpeg
python src/heritage_tour/scripts/build_cantonese_pack.py
colcon build --packages-select heritage_tour
```

生成器通过 [edge-tts 项目](https://github.com/rany2/edge-tts) 调用 Microsoft Edge 在线朗读服务，随后逐段完整解码检查，并保存 MP3。它不会读取麦克风或合成模仿某个真人的声线。需要全部重做时加 `--rebuild`。当前包只有音频，未把模型或访问密钥带入仿真。
