# 非遗智伴：离线完整导览演示

在已有五区展厅和白金色机器人上，增加真实 Gazebo 雷达、AMCL 定位和 Nav2 导航，以及中文网页交互。适用 Ubuntu 24.04、ROS 2 Jazzy、Gazebo Harmonic。五站依次为非遗概览、传统工艺、代表作品、传承历史、互动体验，最后返回入口待命点。

## 启动与操作

先登录 Ubuntu 桌面，关闭以前单独运行的展厅或机器人。打开终端：

```bash
cd ~/moveit_ws
source /opt/ros/jazzy/setup.bash
colcon build --packages-select heritage_hall heritage_robot heritage_tour
source install/setup.bash
ros2 run heritage_tour start_tour.sh
```

在虚拟机浏览器打开 `http://localhost:8765`。大屏页面为 `http://localhost:8765/display`。启动器保留软件渲染防闪烁设置；后台验证也需要已登录的桌面显示环境，使用 `start_tour.sh false`。
软件渲染限制为四个工作线程，给导航保留处理资源；启动期间服务心跳容忍时间为 30 秒，实际移动仍受一秒控制指令、2.5 秒雷达新鲜度和定位门控约束。

1. 等待定位、雷达、导航就绪，再选择“单人到访”或“多人到访”；Gazebo 中会创建对应的实体游客。
2. 选择儿童版、大众版或深度版，以及普通话、粤语（香港）或英文。点击开始表示游客同意接受导览。
3. 机器人实际行驶，到站后显示四部分讲解及互动答题。勾选“启用离线语音”：粤语使用随项目安装的音频，普通话和英文使用浏览器本机语音；缺少语音时保留字幕。默认不使用麦克风、摄像头或云端模型。
4. 可暂停、继续、重复、跳过、下一站和结束返航。“讲解互动完成后自动前往下一站”仍需完成本站答题。
5. 异常演示按钮可添加实体障碍、横穿游客，或模拟掉队、定位丢失、低电量、听不清。故障时先“恢复正常场景”，确认安全后“恢复检查”，再“继续”。实际雷达或定位未恢复时不能继续。
6. 人工接管会取消导航并停车，提示工作人员介入。此演示不自动执行维修、医疗建议、越界问答或真实电源操作。

演示运行期间只由导览运行时向机器人发送速度，请不要同时启动旧的手动驾驶脚本或其他速度发布器。停止启动终端（Ctrl+C）会取消导航并发送停车指令。

## 实现边界

| 能力 | 本次实现 |
|---|---|
| 导航 | 实际轮式物理运动、仿真激光雷达、AMCL、NavFn 与 DWB，实际导航结果驱动到站 |
| 游客识别 | 按钮模拟到访人数和同意导览；不宣称真实视觉或人脸识别 |
| 游客跟随 | 有碰撞的仿真人物沿机器人历史轨迹跟随；不是人体运动学或真实跟踪算法 |
| 安全 | 单人限速 0.27m/s、多人 0.18m/s，近障停车/减速、陈旧传感器停车、故障恢复需确认 |
| 屏幕与灯光 | 网页字幕/地图/表情、机器人脸屏/胸屏/底灯、展厅虚拟大屏随状态切换 |
| 讲解 | 五区 × 三层中文/英文文稿，另有香港粤语离线朗读包；每区含基础、历史、工艺、文化价值 |
| 问答 | 本地已核验条目及来源，匹配不到则转工作人员；不是开放领域智能问答 |
| 创新互动 | 五站任务卡、答题、完成进度、会话统计、实际停靠热度、事件日志 |
| 电量与语音异常 | 明确标注模拟；本次未接真实电池、麦克风、语音识别或手势识别 |
| 机械动作 | 头部与手臂保持固定外观；没有执行挥手或真实触屏驱动 |

雷达为便于避免模型自遮挡设置在头顶 1.58m 高处，低矮展柜依赖静态地图；不能据此证明可检测任意高度的真实障碍物。本模型、质量、地图尺寸均基于图片估算，不作为制造图纸或真实展厅测绘。

## 粤语语音包

先在“讲解语言”选择“粤语（香港）”，可点“试听粤语”，再勾选“启用离线语音”和选择游客到访。到站后会自动播放对应粤语讲解，暂停、重复、断连及播放完成沿用原来的导览状态保护。导览过程中语言选择锁定，结束后可重新选择。

已附 36 段香港粤语女声音频，包含五区三种深度讲解、现有固定问答、单人/三人欢迎、常见告警、告别和试听。原有中文文稿按粤语发音朗读，字幕保留中文，未改写为全套粤语口语文案。播放时只读取虚拟机本地文件；音频生成过程使用联网服务。更新文稿后须重新生成对应音频，缺失时会使用匹配的本机粤语声线或字幕后备，不能把普通话声线当作粤语。详见 [CANTONESE.md](CANTONESE.md)。


重新生成资源需 Pillow：先运行 `src/heritage_robot/scripts/build_robot.py`，再运行 `scripts/build_tour_assets.py` 和 `scripts/build_map.py`。正常使用已生成资源无需重建图片。

场景修改使用持续的 Gazebo Transport 连接，避免每次调用临时命令进程造成的回执丢失。接口依据 [Gazebo Transport 13 服务文档](https://gazebosim.org/api/transport/13/services.html)。
本版本的 `visual_config` 只更新颜色，不能据成功回执认定贴图已切换。屏幕插件在原链接下重建屏幕视觉实体，切换表情/胸屏/大屏贴图，保留碰撞与物理结构；已通过实际渲染截图核对。参考 [Harmonic 渲染实现](https://github.com/gazebosim/gz-sim/blob/gz-sim8/src/rendering/RenderUtil.cc)。
