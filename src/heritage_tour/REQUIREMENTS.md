# 任务书对应表

依据用户提供的四张任务书截图。第六项创新方向末尾截断，仅对应已显示的多语与个性化要求。此表描述实现范围；实际运行结果另见 `VALIDATION.md`。

| 必须覆盖的内容 | 演示入口与实现 | 边界 |
|---|---|---|
| 游客接待 | 单人/三人到访 → 迎宾 → 选择偏好并点击开始 | 人数、到访与同意为按钮输入，不是真实视觉识别 |
| 导览路线组织 | 入口起点 → 概览 → 技艺 → 作品 → 历史 → 互动 → 待命点 | 图片估算地图，停靠点经过碰撞地图检查 |
| 展项讲解 | 每区均有基础介绍、历史背景、工艺特点、文化价值 | 示范策展，不虚构实际馆藏归属/年代/作者 |
| 基础问答 | 当前展区的已核验问题与同义问法，显示来源 | 未匹配问题转人工，不联网补编答案 |
| 安全导航与避障 | 实际 AMCL/Nav2、静态地图、雷达动态障碍层、减速停车、到站判定 | 头顶雷达检测平面有限；低矮固定物体依赖地图 |
| 导览流程控制 | 开始、暂停、继续、重复、跳过、下一站、结束返航 | 暂停/异常会取消当前导航；旧回调不能恢复运动 |
| 异常处理 | 听不清、掉队、受阻、定位丢失、低电量、未知问题 | 听不清/电量/定位故障按钮明确为模拟；实际传感器陈旧也会停车 |
| 人机协同边界 | 自动停车、人工协助提示、人工接管、清除故障 → 恢复检查 → 继续 | 工作人员确认通道、重新集合、检查电源和内容；无自动维修、越权答案 |

| 鼓励创新方向 | 已实现 | 未声称实现 |
|---|---|---|
| 分层讲解 | 儿童版、大众版、深度版，每区都有不同内容 | 自动识别游客年龄 |
| 多模态交互 | 字幕、可选本机离线朗读、表情屏、胸屏、灯带、地图 | 真实麦克风、手势识别、关节挥手；无本机语音包时用字幕 |
| 非遗特色互动 | 五区任务卡、每区知识题、答题反馈和进度 | 真实文创购买、未经授权的交易 |
| 内容联动 | 展区状态驱动机器人屏幕和展厅虚拟大屏；浏览器大屏视图 | 真实投影设备和馆方导视接口 |
| 运营管理 | 本地事件日志、问答统计、停靠热度、配置文件更新内容 | 跨进程持久化统计后台、自动内容发布 |
| 多语与个性化 | 中文/英文、讲解深度与自动下一站偏好 | 方言识别或未展示的任务书后半段 |

## 人工协同操作

- 机器人负责配置范围内迎宾、导航、讲解、互动及停止；工作人员负责核验内容、确认安全、解释未知问题、处理电源及真实设备故障。
- 点击人工接管后保持停止，提示处理原因。导航受阻先清理通道；游客掉队先集合；定位丢失先检查定位；模拟低电量需先清除模拟告警。
- 恢复检查成功只进入暂停待确认状态，仍需显式继续。不能用新开一场导览绕过未清除的故障。
