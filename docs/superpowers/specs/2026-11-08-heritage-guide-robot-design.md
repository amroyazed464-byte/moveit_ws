# 非遗智伴机器人仿真模型

依据用户提供的白金色导览机器人参考图，在既有非遗展厅中建模并实际运行。
沿用 Ubuntu 24.04 / ROS 2 Jazzy / Gazebo Harmonic，以及已验证不再闪烁的软件渲染启动设置。

## 实现选择

采用独立 `heritage_robot` 资源包，程序生成轻量本地网格及表情、胸屏和云纹纹理，SDF 负责动态碰撞和差速底盘。
直接建在 SDF 上能使用现有 Gazebo；仅外观模型不能验证移动，复用原机械臂模型也不符合图片形态。
默认在展厅导览起点生成，提供 ROS 2 速度指令和里程计，以及有时限、结束自动发零的移动演示脚本。

## 明确估算

按图约高 1.55m、底座直径约 0.60m。图片无法确认制造尺寸、质量、传动结构；这些参数为仿真假设。
保留圆头、黑色发光表情、耳部圆环、胸前大屏、白金色外壳、手臂和底部灯带；隐藏式双轮驱动加低摩擦支撑点。
手臂和头部先作为固定外观，屏幕为静态界面。此次完成可控移动，不包含自主导览、语音或触屏业务。

## 验收

本地资源完整，SDF Valid；展厅内生成并落地稳定；通过 ROS 2 指令完成前进、旋转、停止，观察真实位姿而非仅看里程计。
截图核对参考图主要特征。既有测试及新增底盘结构/资源测试通过，按项目要求合并并同步 main。
