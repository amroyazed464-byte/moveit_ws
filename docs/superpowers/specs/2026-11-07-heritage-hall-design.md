# 非遗展厅 Gazebo 场地

用户要求连接虚拟机，按其提供的展厅图片建立场地；用户进一步选择机器人行走、避障使用的 Gazebo 场地。

采用现有 Ubuntu 24.04、ROS 2 Jazzy、Gazebo Harmonic。新增独立 `heritage_hall` 资源包，不修改机械臂演示。
按图片中约 780㎡、高 4.2m 的文字信息估算为 35.4m × 22m。以图像区域 (226,28) 至 (1025,532) 映射平面位置。
五区地面颜色和中文标签使用本地纹理，墙、展柜、隔断、工艺桌凳、中央展柱使用原生几何体，具有静态碰撞。
顶部敞开供俯视观察；入口、出口门洞各宽 2.4m。展品采用简化造型，不追求文物级细节。

比较：纯贴图不能提供避障碰撞；外部精细模型增加下载依赖且图片不足以确定细节；选择本地纹理加原生实体几何。
不包含机器人驱动、Nav2、SLAM 或实车导航验收。图片并非实测施工图，精确尺寸仍需实测。

验收：SDF 官方解析通过，软件中实际加载并核对布局；0.6m 直径机器人在 0.1m 网格中能从入口连通到五区停靠点及出口。
